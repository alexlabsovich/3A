# Телеграм-бот для заметок (pyTelegramBotAPI + Gemini)

Бот сохраняет заметки, показывает их список и отвечает на вопросы
по ним, используя Gemini API (Google AI Studio) как «мозг».
Реагирует только на сообщения от заданного Telegram ID.

## Файлы

- `bot.py` — основной код бота
- `storage.py` — хранение заметок в SQLite (`notes.db`)
- `gemini_client.py` — обращение к Gemini API
- `config.py` — настройки (токены, ID пользователя, модель)
- `requirements.txt` — зависимости

## 1. Получить токен бота

1. В Telegram напиши `@BotFather` → `/newbot` → следуй инструкциям.
2. Скопируй выданный токен вида `123456:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.

## 2. Получить ключ Gemini API

1. Зайди на https://aistudio.google.com/apikey
2. Создай API-ключ (Get API key → Create API key).
3. Скопируй ключ.

## 3. Установка в Termux (Android)

Открой Termux и выполни:

```bash
pkg update -y && pkg upgrade -y
pkg install -y python git
```

Скопируй папку бота на телефон (например через `termux-setup-storage`
и `cp -r /sdcard/Download/telegram_notes_bot ~/`, либо `git clone`,
либо перекинь файлы через любой файловый менеджер/облако), затем:

```bash
cd telegram_notes_bot
pip install -r requirements.txt
```

Если при установке `google-generativeai` возникнут проблемы с
компиляцией зависимостей, дополнительно установи:

```bash
pkg install -y rust binutils
```

## 4. Настройка

Проще всего задать переменные окружения прямо перед запуском:

```bash
export BOT_TOKEN="ТВОЙ_ТОКЕН_БОТА"
export GEMINI_API_KEY="ТВОЙ_КЛЮЧ_GEMINI"
export ALLOWED_USER_ID="8373993954"
```

Либо впиши эти же значения напрямую в `config.py` вместо переменных
окружения — тогда `export` каждый раз делать не нужно.

Чтобы переменные подхватывались автоматически при каждом запуске
Termux, добавь эти три строки в конец файла `~/.bashrc`.

## 5. Запуск

```bash
cd telegram_notes_bot
python bot.py
```

Если всё настроено верно, в консоли появится строка
`Бот запущен. Разрешённый пользователь: 8373993954`.

### Как узнать свой Telegram ID

Если понадобится проверить/сменить ID — напиши боту
`@userinfobot` в Telegram, он пришлёт твой числовой ID.

## 6. Чтобы бот работал в фоне (не завершался при закрытии Termux)

Вариант А — `nohup`:

```bash
nohup python bot.py > bot.log 2>&1 &
```

Вариант Б — через `tmux` (удобнее для просмотра логов):

```bash
pkg install -y tmux
tmux new -s notesbot
python bot.py
# отключиться от сессии, не останавливая бота: Ctrl+B, затем D
# вернуться позже: tmux attach -t notesbot
```

Чтобы Android не «убивал» Termux в фоне, включи в приложении Termux
удержание пробуждения:

```bash
termux-wake-lock
```

и в настройках Android разреши Termux работать без ограничений
энергосбережения (обычно: Настройки → Приложения → Termux →
Батарея → «Без ограничений»).

## Использование бота

- `/add <текст>` — сохранить заметку
- `/list [страница]` — список заметок
- `/show <id>` — показать заметку целиком
- `/del <id>` — удалить заметку
- `/ask <вопрос>` — задать вопрос по заметкам
- Любой обычный текст без команды — тоже воспринимается как вопрос
  к заметкам (аналог `/ask`)

Поиск контекста для ответа делается простым сопоставлением слов
запроса с текстом заметок (без сторонних сервисов эмбеддингов) —
для личного блокнота на несколько сотен заметок этого достаточно.
Если понадобится более умный семантический поиск (например, при
сотнях заметок и нечётких формулировках), можно позже добавить
эмбеддинги через тот же Gemini API — скажи, и я это добавлю.

## Возможные доработки

- Редактирование существующей заметки (`/edit <id> <новый текст>`).
- Автоматические теги/категории для заметок через Gemini.
